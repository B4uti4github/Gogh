# Contributing

Gracias por querer contribuir a Gogh. Lee esto antes de abrir issues o PRs.

Cómo contribuir
- Abre un issue para discutir grandes cambios o propuestas de features.
- Para cambios pequeños: crea una rama nueva, haz commits claros y abre un Pull Request con una descripción concisa.

Estilo de código
- Zig: sigue la guía de estilo oficial de Zig cuando aplique.
- Mantén el código comentado y con tests básicos cuando sea posible.

Pull requests
- Asegurate de actualizar ROADMAP.md/CHANGELOG cuando corresponda.
- Describe el cambio, el motivo y cómo probarlo.

Testing y CI
- El flujo de CI ejecutará build principal con Zig. Para builds de ESP32, revisa platform/esp32/README.md.

Comunicación
- Usa issues para discusiones largas. Usa PRs para cambios listos para revisar.

Gracias por colaborar — cualquier contribución es bienvenida.
