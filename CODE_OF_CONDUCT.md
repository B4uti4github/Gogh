# Plantilla básica de CODE-OF-CONDUCT (Contributor Covenant v2.0 simplificado)

Nuestro objetivo es mantener una comunidad acogedora y respetuosa. Se espera que todos los contribuyentes sigan estas normas:

- Sé respetuoso y considerado.
- Evita lenguaje ofensivo y ataques personales.
- Respeta la privacidad de los demas.

Si sufrís o presencias un comportamiento que viole esta guía, abrí una issue o contactanos directamente.
